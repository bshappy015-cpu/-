# 유튜브 제작 팀 설정 양식

이 파일을 프로젝트의 `teams/<team-id>/team-profile.md`로 복사해 팀마다 작성한다. 대괄호는 실제 값으로 바꾼다. 특정 주제가 정해지지 않은 필드는 미정으로 둘 수 있고, 실제 제작을 막는 항목만 그때 확인한다.

## 팀과 채널

- 팀 ID: [팀마다 구분되는 고유 ID]
- 팀 이름: [표시할 이름]
- 채널 또는 프로젝트: [채널명·URL 또는 미정]
- 주요 주제: [이번 팀이 지속해서 다룰 주제]
- 다루지 않을 범위: [제외할 주제·표현]
- 대상 시청자: [누가 어떤 문제·관심으로 보는지]
- 채널의 약속과 구독 가치: [다음 영상도 볼 이유]

## 제작 방향

- 주력 형식: [쇼츠 / 롱폼 / 둘 다 / 기타]
- 목표 길이·화면비: [주력 기준, 개별 영상에서 조정 가능]
- 톤·내레이션·시각 스타일: [말투·분위기·연출 선호]
- 참고 채널·영상·기타 자료: [URL·파일과 참고할 점]
- 고유한 차별점: [이 팀이 더 잘 전달할 가치]
- 사실 확인 시 주의할 분야·시점: [주제에 맞는 검증 기준]

## 기본 시청 경험

- 첫 도입부: 시청자의 질문과 볼 이유를 즉시 전달한다.
- 본문: 구간마다 새 가치·전개를 제공하고 초반의 약속을 이번 편 안에서 충족한다.
- 다음 편: 구체적인 후속 질문·효용을 예고하고 미확정 일정은 약속하지 않는다.
- 좋아요·구독: 가치가 전달된 뒤 자연스럽게 제안하고 각각의 실제 반응을 확인한다.
- 팀별 시리즈·연재 방향: [독립 회차의 가치와 다음 편 연결]

## 실행 환경과 근거

- 사용 가능한 영상·편집·음성 도구: [이미 연결된 도구]
- 예산·일정·허용된 유료 작업: [현재 승인 범위]
- 사용 가능한 자산·이용권: [경로와 허용 범위, 비밀값 제외]
- 채널 분석 자료: [제공 가능한 파일·기간·지표, 없으면 미제공]
- 팀별 성장 목표와 관찰 기간: [비교할 실제 지표, 성과 보장 아님]

## 자료 구분

- 이 팀의 결과물: `productions/<team-id>/<project-id>/`
- 다른 팀 자료 공유 시: 원래 팀·출처·이용 조건과 현재 팀에 적용할 근거를 기록한다.
- API 키·비밀번호 등 비밀값은 이 문서에 넣지 않는다.

총괄은 이 설정을 읽어 개별 영상의 `brief.md`를 작성한다. 성장 담당은 이 팀의 실제 자료만으로 `growth-plan.md`와 게시 후 `performance-review.md`를 작성하고, 데이터가 없으면 가설·측정 계획으로 표시한다.
